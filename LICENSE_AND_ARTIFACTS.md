# Artifact Licenses and Use

This software package is a review-time supplement for reproducing the CARE finite-pool replay experiments.

The included code is intended for non-commercial research evaluation and reproducibility. The package does not grant additional rights to the upstream HTE datasets. Dataset licenses and checksums are documented in the separate data archive.

The replay protocol uses only public candidate features, revealed outcomes, and logged optimizer state at decision time. Oracle values and hidden outcome columns are used only by the offline evaluator after an action is selected.
