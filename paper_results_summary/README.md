# Paper Result Summaries

These files contain clean aggregate summaries reported in the paper tables:

- `main_results.csv`: main matched replay table, seed means, 95% bootstrap confidence intervals, and final simple regret.
- `ablations.csv`: mean final-best and AUC drops from full CARE.
- `diagnostics.csv`: capacity-control and intervention-log diagnostics.

The raw per-seed logs are not included in this ARR upload package to keep the supplement compact and review-facing.
